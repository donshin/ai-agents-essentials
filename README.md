# AI Agents Essentials

Workbook for the workshop **AI Agents Essentials: Build Your First Working Agent (No Coding Required)**.

## [Open the workbook](https://docs.google.com/document/d/1EJWBWCNv0KtFKdNKipth5xrEXsdT8uJe/edit?usp=sharing&rtpof=true&sd=true)

- Open the workbook on the same computer as your agent harness (Claude Cowork, Microsoft Copilot Cowork, or ChatGPT Work), so that you can copy and paste each prompt.
- You cannot type in the workbook. Write your answers on paper or in a notes app.
- To keep a copy, use File → Download in the workbook.

Workshop by Don Shin, [CrossComm](https://crosscomm.com).
